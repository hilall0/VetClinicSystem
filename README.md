# Veteriner Kliniği Randevu ve Hasta Takip Sistemi
**Öğrenci Adı:** Hilal İrem Patan\
**Öğrenci Numarası:** B241210001\
**Ders Grubu:** 1B\
**GitHub Bağlantısı:** https://github.com/hilall0/VetClinicSystem/tree/main\
## Bu proje, ASP .NET Core MVC ve PostgreSQL kullanılarak geliştirilen bir Veteriner Kliniği Randevu ve Hasta Yönetimi Takip Sistemidir.
Sistem, veteriner kliniklerinin sunduğu hizmetleri, hekimlerin uzmanlık alanları, verebildikleri hizmetler ve müsaitlik saatlerini, evcil hayvanların aşı/muayene geçmişleri ve randevu süreçlerini yönetmeyi amaçlamaktadır.\
Ayrıca sistem, yapay zeka asistanlarının doğrudan çağırabileceği bir MCP(Model Context Protocol) sunucusu barındıracaktır.
